# 🐝 Particle Swarm Optimization (PSO) algorithm 
# Метод роя частиц

Курсовая работа по дисциплине «Алгоритмы и структуры данных».

### **Тема:** Исследование и реализация метода роя частиц для решения задач оптимизации.

Проект представляет собой клиент-серверное веб-приложение для визуализации алгоритма Particle Swarm Optimization (PSO). Алгоритм решает задачи многомерной непрерывной оптимизации, а интерактивный интерфейс позволяет в реальном времени наблюдать за поведением «пчел» (частиц), искать локальные и глобальные минимумы сложных функций.

## Установка и запуск (Локально)

Для запуска приложения потребуется [Python](https://www.python.org/) и [Node.js](https://nodejs.org/).

### 1. Запуск серверной части (Backend)
```bash
cd backend
python -m venv venv

# Активация окружения (Windows):
venv\Scripts\activate
# Активация окружения (Mac/Linux):
source venv/bin/activate

pip install flask flask-cors pytest
python app.py

REST API сервер запустится на http://127.0.0.1:5000.
```

### 2. Запуск клиентской части (Frontend)

Откройте новый терминал и выполните:

```Bash
cd frontend
npm install
npm run dev
Интерфейс приложения будет доступен в браузере по адресу http://localhost:5173.
```

### Модульное тестирование
Вычислительное ядро алгоритма и логика ограничения границ полностью покрыты тестами. Для проверки работоспособности математической модели выполните:

```Bash
cd backend
pytest -v
```
